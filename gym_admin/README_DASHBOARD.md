Dashboard
---------

Se agregó un dashboard a `home.html` con:
- Cards de resumen de clientes
- Gráfica de ingresos/egresos por mes (Chart.js)
- Lista de cumpleañeros de la semana
- Botones rápidos que redirigen a los módulos existentes con filtros

APIs disponibles (JSON):
- /api/financials/monthly
- /api/clients/summary
- /api/clients/birthdays
- /api/members/expiring

Reinicia el servidor de Flask para que los cambios se carguen.
